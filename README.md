### 구조 설명

`curriculum-data\`: 데이터셋 확보를 위한 작업이 이뤄진 디렉토리입니다.

`scripts`: 서비스 핵심 실행 코드에 포함되지 않지만, 프로젝트 개발/관리/데이터 처리/자동화 등에 필요한 보조 실행 파일을 모아둔 디렉토리입니다.
